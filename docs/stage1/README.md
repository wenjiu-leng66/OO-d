# 一期检查入口

一期交付包括 RBAC0 面向功能后端、完整界面原型、统一 API、数据库和服务器运行材料。本次课程检查分为“助教现场实操”和“老师口试”两个环节，**不是** RBAC0/RBAC1 两个开发阶段。

## 助教现场检查

必须在预约老师时段之前完成助教检查，否则预约作废。助教每天一位，在平时上课教室检查；每组约二十多分钟是排练参考，不是固定承诺时长。

| 必查项 | 现场准备 | 证据与判定 |
| --- | --- | --- |
| 原型打开且运行 | [服务器原型](http://124.70.42.35:8080/)；准备各类合成账号 | 登录、导航、角色/授权、台账、错误/空态；说明当前 mock 边界 |
| 后端已部署服务器 | 实际源码 SHA、镜像/容器状态、健康检查 | 接口调用到真实 Java/MySQL；不能用本地 IDE 启动冒充服务器部署 |
| API 已归档且现场可调 | [指定 Swagger 入口](http://124.70.42.35:8080/swagger-ui/index.html?url=/api-design/openapi.yaml)及 `api/openapi.yaml` | 当场登录、带 Cookie 调用允许与拒绝用例；归档口径请助教核对 |
| 有架构的后端单元测试 | [结构化设计](../design/structured-design.md)、隔离测试与整合测试分层 | `mvn -f backend-procedural/pom.xml clean verify` 现场运行 |
| 测试报告与覆盖率 | Surefire 与 JaCoCo | 对应同一被测版本；能解释未覆盖部分及不能证明的事项 |

服务器公开 GET 检查与当前本地实测见 [验证记录](verification-record.md)。完整命令见 [自测步骤](self-test.md)，逐条需求见 [41 条覆盖](requirement-coverage.md)，异常与边界见 [检查清单](review-checklist.md)。

## 老师口试

老师主要依据后端设计代码、提交的测试情况、API 文档与代码提问，范围为结构化设计与需求，首次检查的需求理解须准确。原型/API 界面不重复作为主展示。按“需求 → 功能分解/数据流 → 代码 → 单元测试 → 运行证据”回答，不能只背术语。

无领导小组式回答，任何成员可补充；每人都要讲到自己的贡献，全程不发言个人记 0 分。超过半小时迟到会使时段作废；具体预约、教室及候场安排以通知为准。已知口试教室 211，下午场教室尚未确认。JavaEE 与 OOAD 合并口试，未选 JavaEE 的成员入场说明。

成员分工见 [责任表](../planning/team.md)，逐模块讲解和 JavaEE 实验对照见 [口试准备](oral-review.md)。课程视频及实验之外的内容不擅自扩大成项目已实现功能。

## 范围和证据

真实后端实现登录、改密、用户/角色、授权、目录、门户及员工台账的 RBAC0；原型可独立展示。继承和 OO 后端属 RBAC1 阶段，约束、激活角色和审计属后续阶段。一次检查的两环节不能改变这个实现边界。

全量数据基准为 111 组织、18 系统、115 模块、359 功能点、2154 清单权限、10000 员工加 admin；原清单五角色授权 3549，平台补充部门管理员 6 条。合成数据、H2、原型和公开 GET 的成功均不能替代正式数据导入、MySQL 事务、业务接口和服务器重启验证。
