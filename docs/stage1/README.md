验收口径以用户 2026-10-18 的说明为准：**完整后端（允许不接前端）、完整界面原型、API 设计，全部上传到服务器并且可以运行。** 后端与界面原型可以分别检查；界面演示通过不能替代真实接口、持久化和服务器验收。

执行范围按用户后续明确要求收敛为：**本轮只完善仓库和本机验证，不连接或操作用户服务器。** 部署脚本及说明已经准备，留待用户自行部署并执行服务器检查。
