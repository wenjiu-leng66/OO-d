# 首批准备任务

以下可用于创建六个 Task Issue；成员编号是分工角色，真实 Assignees 在邀请账号后选择。

| 主责 | 任务 | 完成标准 |
| --- | --- | --- |
| 成员 1 | 数据字典与组织映射草案 | 来源字段、用户名唯一键、部门映射、负责人关联、导入核对规则已记录，作者自检完成 |
| 成员 2 | 基础页面原型与前端规范 | 登录、用户、部门原型；分页、错误反馈、路由与公共组件边界已明确 |
| 成员 3 | 角色权限配置原型 | 资源目录、角色分配、权限按钮规则及后续层级页面边界已说明 |
| 成员 4 | RBAC0 功能分解与接口草案 | 登录、角色、授权流程与 API 的输入输出、认证和失败分支已记录 |
| 成员 5 | 领域模型与 OO 设计草案 | User、Role、Permission、层级、约束的职责与关键序列已记录，作者自检完成 |
| 成员 6 | 验收预期和接口一致性清单 | 清单歧义有来源位置；允许与拒绝场景、双后端比较方法及联调标准已记录 |

共同任务：每人可直接更新main，或自选任务分支/PR方式练习提交与同步。组长协调老师问题、账号及进度，不指定专属合并人；全体成员均可编辑和自行合并，API与数据口径由相关成员对接统一。
