# 验收矩阵

执行事实见 [一期验证记录](../stage1/verification-record.md)，41条追溯见 [需求覆盖](../stage1/requirement-coverage.md)，检查命令见 [自测步骤](../stage1/self-test.md)。本矩阵定义预期，未填入证据的项目不代表已通过。

| 编号 | 阶段 | 场景 | 预期与证据要求 |
| --- | --- | --- | --- |
| T-01 | 一 | 未登录、登录/改密/退出、停用旧会话 | 未登录/失效401；首次改密限制403；退出旧Cookie失效；真实HTTP与后端测试 |
| T-02 | 一 | 有权限/无权限访问同一操作 | 分别允许/403；直调写接口不能绕过按钮；原型与后端分别记录 |
| T-03 | 一 | 分配/撤销角色、修改授权/停用角色 | 下一请求生效；整组替换、旧version409、失败整体回滚 |
| T-04 | 二 | 多层继承与重复路径 | 权限正确且去重 |
| T-05 | 二 | 添加自环或间接环 | 拒绝并保持原状态 |
| T-06 | 三 | 分配静态冲突角色 | SSD拒绝且原因明确 |
| T-07 | 三 | 同时激活动态冲突角色 | DSD拒绝，允许的分配不受混淆 |
| T-08 | 三 | 超过人数上限及并发分配 | 基数不突破上限 |
| T-09 | 一 | 篡改URL或请求体ID，SELF/DEPT范围 | 越权403 OUT_OF_SCOPE；范围外/不存在不泄露对象资料；DB不变 |
| T-10 | 三 | 继承引入约束冲突 | 不能绕过约束 |
| T-11 | 二 | 两后端运行同一请求序列 | 独立等价初始库，业务结果与最终状态等价 |
| T-12 | 一 | 导入与重复导入 | 核对规模/角色/范围，清洗可定位，业务快照一致；合成和全量分记 |
| T-13 | 三 | 函数式独立计算 | 输入输出明确、无共享状态副作用 |
| S1-DEPLOY | 一 | 上传服务器并运行 | URL、SHA、迁移版本、健康、外网HTTP、重启持久化均有记录 |
| S1-UI/API | 一 | 完整原型与API设计 | 页面身份演示、构建、OpenAPI与真实接口一致 |

报告记录日期、版本、环境、数据、操作、预期、实际、证据和限制。CI不是云部署或原Excel全量验收的替代品。第二/三阶段项目本次为“不在一期”，不计作本次后端缺陷。
