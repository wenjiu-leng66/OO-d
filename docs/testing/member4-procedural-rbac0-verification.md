## 实现与验证结果

以下能力已按默认假设实现，并通过集成测试（47 个用例全部通过，JaCoCo 指令覆盖率 95%）与运行时冒烟验证：

- Java / Spring Boot 面向功能后端工程：`mvn clean test` 47 个用例全部通过；`mvn spring-boot:run` 启动正常，Swagger UI 与 H2 控制台可访问。
- 密码加盐哈希（BCrypt）、登录会话建立与退出失效。
- H2 建表与合成演示数据初始化、员工号/手机号唯一约束（切 MySQL 后按方言核对）。
- 每次请求的权限校验与默认拒绝、本人范围拒绝、受保护账号（本人 / 超级管理员）改状态与删除拦截。
- 创建 / 启停 / 删除用户接口（201 / 200 / 204 与错误分支：重复、未知部门、未知角色、super-admin 角色保护）。
- 替换集合的原子事务与并发版本冲突（409）。
- 运行时冒烟：登录 200 → 查询本人权限（14 个权限码）→ 越权 403 → 创建 201 → 停用 200 → 删除 204 → 未登录 401。

遗留待补（随后与成员 1、2、3、5、6 协作）：

- 账号停用后既有会话立即失效策略。
- 部门管理员「仅本部门」范围过滤；真实数据库（MySQL）联调。
- 两套后端同一请求序列的结果与状态一致性对比。
