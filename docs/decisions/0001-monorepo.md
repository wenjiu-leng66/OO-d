# ADR-0001：单仓库、一套前端与两套后端

日期：2026-10-05。状态：仓库组织方式采用；具体运行框架与复用边界待课程确认。

## 背景

六人小组需要统一文档、接口、数据库结构，并分别展示两种授权实现。

## 决定

前端、两套后端、API 契约、数据库迁移和文档使用一个仓库。全体小组成员均可直接编辑、提交和推送main，或自行合并PR。短期分支与PR为可选协作方式，不设指定负责人或强制人工审批；按变更内容记录必要验证。

两套后端的外部契约一致、核心授权逻辑独立；测试使用相同预期和等价的独立初始数据。当前不会为模拟框架完成而加入无意义的业务代码。

## 影响

接口变化需要协调多个目录。数据库变更统一迁移。前端能按配置连接不同后端。目录共存不自动证明两种范式已经完成，仍需实际设计、代码与测试证据。
