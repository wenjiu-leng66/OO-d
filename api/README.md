# API 契约

主责：接口作者；成员 6 维护一致性，前端成员确认可用性。

`openapi.yaml` 是协作中的权威接口文件。成员 6 已整理 RBAC0 第一版接口草案，覆盖认证、当前权限、用户、部门、角色、权限目录、用户角色替换和角色权限替换。状态为**草案 / 待后端联调**，尚无已实现接口或真实 API 测试结果。接口规则见 [接口约定](../docs/standards/api-contract.md)，测试设计见 [成员 6 RBAC0 API 测试用例](../docs/testing/member6-rbac0-api-test-cases.md)。

每个接口正式开发前由接口作者和成员 6 核对路径、方法、认证、请求、响应、状态、错误码、所需权限和范围。当前 Cookie/Token、对象越权返回 403/404、范围合并和权限变化生效时点仍待确认。变更经讨论后同时更新前端、两种后端和测试。

可导入兼容 OpenAPI 的客户端工具查看。工具中的编辑结果也需要导出并通过 PR 更新本文件，不另建一份互相矛盾的接口标准。

成员 2 的当前实现、接口建议与待确认事项见 [API 协作反馈](proposals/member2-api-coordination-feedback.md)。该反馈不替代正式 OpenAPI。
