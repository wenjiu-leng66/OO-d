RBAC 第一期检查入口

交付内容：完整后端、完整界面原型、API 设计，以及服务器运行配置。

  1. 打开完整界面原型：查看登录、门户、用户、部门、角色授权和台账交互。
  2. 打开真实后端 Swagger UI：通过 Cookie 会话实际登录并调用接口。
  3. 查看／下载 API 设计（OpenAPI）。
  4. 检查后端与数据库健康状态。

界面原型使用浏览器内的模拟数据。真实后端连接 MySQL，实际权限和持久化通过 Swagger 或 HTTP 自测脚本验收。原型登录密码与服务器后端密码分别管理。

后端检查顺序

先登录，再执行 GET /api/v1/me 和权限查询；依次检查未登录、无权限、本人／本部门范围、管理员保护、版本冲突、停用后旧会话和退出。随后重启容器，验证创建的数据仍然存在。

后端演示账号与初始密码由部署负责人提供。首次登录后按接口提示改密。自测命令和预期结果见仓库 deploy/README.md。
