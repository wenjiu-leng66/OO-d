# 输入数据

课程输入是员工信息、部门信息、应用功能权限清单三份 Excel。此仓库不保存原始表。

原始数据由组长通过受控方式提供，开发者在本地放到 `data/raw/`。该目录内容被 Git 忽略；提交前仍检查 `git status` 和暂存差异。

用户名作为业务唯一标识，电话按文本处理，负责人最终关联用户 ID。分公司与部门按明确规则映射组织节点，姓名重名不等于账号重复。

功能清单先恢复合并单元格的系统和模块归属，再规范操作与范围，记录原表位置和清洗决定。权限空白、`view` 混写、本人范围和“全部”的含义见 [待确认问题](../docs/requirements/questions.md)。具体清洗、组织映射和核对规则见 [导入质量规则](../docs/database/import-rules.md)，导入脚本的输出也写在 `data/raw/`。

`samples/` 中的数据全部合成，用于讨论字段和协作，不能当作真实导入后的完整数据或正式角色映射。
